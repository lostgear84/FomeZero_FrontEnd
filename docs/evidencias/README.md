## Alcance das evidências

- As capturas registram estados da interface; não substituem a demonstração ao vivo.
- A sequência de solicitação e resposta documenta processamento simulado por regras locais.
- A captura móvel registra a área do Doador em 400 px, não uma auditoria de todas as telas.
- A captura técnica registra build e lint daquela execução.
- O index.html visível na captura técnica ainda contém o idioma anterior à correção para pt-BR.
- A revisão com zoom de 200% foi informada pelo operador, mas não possui captura neste conjunto.
- As imagens não comprovam integração com AIPA, GENAI, IoT ou VCIA.
